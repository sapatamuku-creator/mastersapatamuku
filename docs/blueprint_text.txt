Ringkasan Eksekutif & Penyesuaian Struktur  Dokumen ini merevisi cetak biru pengembangan   SapaTamu.id versi 2.3   untuk menyelaraskan sistem integrasi data secara presisi dengan struktur sheet yang sudah ada pada sistem Anda, tanpa melakukan improvisasi peletakan kolom. Pembaruan ini berfokus pada sinkronisasi data dari halaman konfirmasi   {subdomain}.rsvp.html   yang disebarkan melalui   link blast , memetakan data konfirmasi kehadiran ke kolom yang telah ditentukan di  Sheet1 , serta mengirimkan data ucapan ( wishes ) langsung ke tabel   wishes_queue   di   Supabase   untuk kebutuhan tampilan   Welcome Sign .  2. Pemetaan & Penempatan Kolom Spreadsheet Eksisting  Sistem backend wajib mematuhi penempatan data pada sel dan kolom spesifik berikut sesuai dengan template sheet aktif:  Data / Parameter   Lokasi Kolom / Sel Eksisting   Fungsi & Keterangan  Link Invitation   KOLOM B5   Tempat input manual untuk tautan utama undangan digital (Undangan Web).  Link RSVP   KOLOM C5   Tempat input manual untuk tautan halaman konfirmasi RSVP (Subdomain/Spesifik). 3. Mekanisme Aliran Data & Integrasi Supabase  A. Pengisian Form RSVP Dinamis  Saat tamu membuka tautan konfirmasi RSVP (yang jalurnya merujuk pada konfigurasi di   C5 ), sistem akan memvalidasi data berdasarkan baris nama tamu. Jika tamu menyatakan   Bisa Hadir , form akan membuka input jumlah anggota yang akan dibawa. Nilai angka ini akan langsung dikirim dan memperbarui nilai pada   Sheet1 KOLOM H   untuk baris tamu bersangkutan.  B. Integrasi Sinkronisasi Tabel Supabase (wishes_queue)  Di bagian bawah formulir RSVP, tamu dapat mengisi kolom ucapan selamat dan harapan (wishes). Data ucapan ini akan langsung di-insert ke dalam database produksi Supabase pada tabel  public.wishes_queue   . Berdasarkan struktur tabel eksisting, data dipetakan ke kolom:  id   (int8 - auto increment)  ssid   (text - ID/Token Undangan unik untuk mencocokkan acara pengantin)  name   (text - Nama lengkap tamu pengirim ucapan)  ucapan   (text - Isi doa dan ucapan dari tamu)  created_at   (timestamptz - Waktu log otomatis)  4. Penanganan Output untuk Welcome Sign  Dengan pemetaan yang presisi ini, modul display   Welcome Sign / AI Watcher (RTX Mode)   akan membaca antrean data terbaru langsung dari tabel   wishes_queue   di Supabase untuk memunculkan ucapan secara  real-time , sementara manifes jumlah kedatangan dipantau langsung melalui   KOLOM H   pada spreadsheet untuk keperluan validasi saat tamu melakukan QR Check-in di lokasi acara. • • • • • ◦ ◦ ◦ ◦ ◦  SapaTamu.id Blueprint v2.3 (Revisi)   2
