SaaS Architectural Blueprint: sortir.sapatamu.id  Fase Pengembangan: Ekspansi Multi-Tenant B2B | Database Standar: Supabase  1. Strategi Rebranding & Skalabilitas SaaS  Keputusan   memindahkan   penamaan   dari   tingkat   brand   agensi   (Knowhere)   ke   infrastruktur   utilitas   generic ( sortir.sapatamu.id ) adalah langkah validasi pasar yang krusial. Sistem ini kini diposisikan sebagai produk B2B SaaS ( Photo Culling Micro-SaaS ) yang dapat disewa oleh ratusan vendor fotografi pernikahan/event lainnya. Dengan menggunakan   Supabase   sebagai real-time database, arsitektur ini mendukung performa tinggi untuk penanganan sinkronisasi status checklist secara instan tanpa membebani core database bawaan Sapatamu.id.  2. Pemetaan Struktur Routing & Arsitektur Sistem  Aplikasi berjalan di bawah satu subdomain terdedikasi dengan tiga pilar navigasi utama:  Endpoint URI   Akses Kontrol   Mekanisme Kerja & Alur Logika  /login   Publik / Vendor baru Pendaftaran Akun Vendor & integrasi Payment Gateway langsung. Registrasi sukses memicu webhook otomatis yang mengubah flag status akun menjadi   active = true .  /:event_slug   Klien Vendor Halaman seleksi foto (Culling Node). Menampilkan grid foto dari Google Drive via Supabase CDN cache. Fitur autosave real-time berjalan setiap kali checklist berubah.  /dashboard   Vendor Terautentikasi Control Panel utama Vendor. Digunakan untuk membuat link event baru, menentukan limitasi kuota foto klien, memantau riwayat seleksi, dan mengeksekusi script lokal.  3. Spesifikasi Detail Implementasi Modul  Modul A: Onboarding & Gateway (/login & /register)  Form Entry Singkat:   Hanya membutuhkan Nama Vendor, Email/Password, dan Nomor WhatsApp Utama (yang difungsikan sebagai nomor tujuan penampung data API manual klien).  Frictionless Payment Checkout:   Menggunakan arsitektur form pendaftaran Sapatamu.id yang disederhanakan, langsung melempar Snap Token ke Payment Gateway (Midtrans/Xendit).  Supabase Auth Trigger:   Begitu pembayaran bernilai sukses, status otentikasi Supabase dan profil vendor diperbarui, memberikan akses instan ke   /dashboard .  Modul B: Real-Time Client Culling Page (/:event_slug)  Untuk menjaga performa rendering ratusan foto dalam satu halaman, manipulasi data checklist dilakukan di tingkat client-side state dan langsung disinkronisasikan ke Supabase menggunakan fungsionalitas   Realtime / PostgREST upsert . • • •  Sapatamu Ecosystem - SaaS Expansion Blueprint (Confidential)   1
