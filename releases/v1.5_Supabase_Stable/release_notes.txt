Release v1.5 - Supabase Stable
Tanggal: 28 Mei 2026

Pembaruan Utama:
1. Migrasi penuh sistem frontend (operasional resepsionis, angpao, wa blast, dsb) ke infrastruktur event-driven Supabase-First.
2. Penyelesaian perbaikan bug mojibake (karakter aneh UTF-8) yang sebelumnya mengenai keywords Javascript dan beberapa ikon UI. Semua sudah diverifikasi bersih 100%.
3. Modul Welcome Sign dipertahankan menggunakan GAS untuk metadata dan slideshow agar tetap terhubung dengan halaman konfigurasi (config.html), namun antrean real-time tetap membaca langsung ke Supabase (delay < 300ms).
4. Upgrade halaman Owner, Login, dan Upgrade untuk menangani token akses yang lebih aman dan sinkronisasi metadata secara cepat.
