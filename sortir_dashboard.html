Skrip Otomatisasi

Skrip ini digunakan untuk menyalin file foto (RAW & JPG) pilihan klien dari folder kerja lokal Anda ke subfolder culling secara otomatis. Cukup tempelkan teks hasil sortir dari WhatsApp klien, atau hubungkan dengan event di atas untuk menarik data pilihan secara real-time.

0 nama file terdeteksi

1. Unduh Skrip: Masukkan daftar nama file di atas (atau ambil dari database) lalu unduh skrip sesuai sistem operasi Anda.

2. Letakkan Skrip: Pindahkan file skrip yang diunduh (cull_photos.bat untuk Windows, atau cull_photos.command untuk Mac) ke dalam folder kerja lokal berisi file foto RAW & JPG asli Anda.

3. Jalankan Skrip: Klik ganda file skrip tersebut. Skrip akan memproses daftar foto, membuat subfolder baru bernama culling_results, dan menyalin foto pilihan klien (file RAW & JPG yang sesuai) ke subfolder tersebut secara otomatis dalam hitungan detik.

⚠️ Khusus macOS: Saat pertama kali menjalankan skrip .command, jika muncul peringatan "permission denied", buka Terminal, ketik chmod +x lalu seret file skrip ke Terminal dan tekan Enter. Setelah itu, skrip dapat dijalankan dengan aman.
