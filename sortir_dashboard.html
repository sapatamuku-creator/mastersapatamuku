Panduan Skrip Salin Cepat PnP (Plug and Play)

Duplikasi file RAW & JPG pilihan klien ke folder komputer Anda secara otomatis dalam sekali klik tanpa python / dependensi rumit.

1. Download file daftar nama foto terpilih (**`foto_pilihan.txt`**) melalui tombol unduh di sebelah event klien.
2. Download skrip PnP di bawah sesuai dengan OS komputer Anda, lalu letakkan file skrip tersebut di **folder yang sama** dengan file RAW/JPG asli.
3. Klik dua kali skrip tersebut untuk dijalankan, setujui konfirmasi awal, dan sistem akan otomatis menduplikasi semua file RAW/JPG terpilih ke subfolder baru bernama **`culling_results`**.
💻

Windows (.bat)

Launcher instan klik-dua-kali yang menjalankan fungsi pencarian PowerShell berkecepatan tinggi.

🍎

macOS (.command)

Skrip Command terminal kompatibel dengan Mac OS. Cukup klik untuk memilah raw file instan.
