# 04 — Color: Rasio 60:30:10 + Palet Industri

> Sumber: LogRocket 60-30-10, UXPin color distribution, Visily/Hype4/Mockitt guides
> + hallmark color.md (OKLCH) + taste-skill LILA rule + color consistency lock.
> Asal: interior design → UI. Tujuan: hierarchy warna yang mata bisa scan <8 detik.

---

## 4.1 Definisi 60:30:10

```
60% Dominant  — background & primary surface. Netral/low-saturation. Set tone.
30% Secondary — cards, sidebars, supporting surfaces. Muted tint brand color.
10% Accent    — CTA, active states, links, badges. Paling vibrant, paling jarang.
```

Rasio = **area visual**, bukan jumlah token. Satu tombol 10% bisa lebih impactful daripada 10% area literal.

```
Contoh SapaTamu warm:
 60% #F5F0E8 (Warm Sand / paper)  — background, canvas
 30% #8B7355 (Stone / secondary)  — cards, nav, section chrome
 10% #C0392B (Rose/vermillion)    — CTA, price, active, notif dot
Tints/shades dari 3 hue yang sama boleh — jangan tambah hue ke-4 yang merusak rasio.
```

## 4.2 Cara memilih tiap slot

| Slot | Rule seleksi | Contoh |
|------|--------------|--------|
| **Dominant 60%** | Netral: white / off-white / light grey (light) atau near-black `oklch(0.18 ...)` (dark). Eye rest. | `#F5F0E8`, `#FAFAF9`, `#0A0A0B` |
| **Secondary 30%** | Brand color atau hue komplementer dominant, muted/mid-tone agar support accent bukan fight. | Stone, Slate, muted brand tint |
| **Accent 10%** | Paling vibrant + high-contrast vs 60 & 30. Grab attention. Satu hue saja. | Emerald / Electric Blue / Deep Rose / Burnt Orange — saturasi <80% default |

**Stretch:** pakai tints/shades dari 3 hue (lighten/darken) untuk depth tanpa hue baru.

## 4.3 OKLCH discipline (dari hallmark color.md)

- Definisikan tokens di `:root` sebagai OKLCH, refer via `var()`:

```css
:root {
  --color-paper: oklch(0.97 0.02 85);
  --color-ink: oklch(0.18 0.01 85);
  --color-secondary: oklch(0.65 0.08 85);
  --color-accent: oklch(0.62 0.18 25);
  --color-accent-hover: oklch(0.58 0.20 25);
  --color-success: oklch(0.65 0.15 145);
  --color-warning: oklch(0.75 0.15 75);
  --color-error: oklch(0.60 0.20 25);
  --color-paper-2: oklch(0.95 0.02 85); /* tint of paper untuk cards */
}
.hero { background: var(--color-paper); color: var(--color-ink); }
.btn-primary { background: var(--color-accent); color: white; }
.btn-primary:hover { background: var(--color-accent-hover); }
```
- **Locked tokens:** setelah theme dipilih, jangan inline hex/oklch di component — lift ke token block lalu refer.
- Tint pure black/white ke anchor hue (jangan `#000`/`#fff` flat).

## 4.4 Mapping ke design system tokens (UXPin)

```
60% → surface tokens  (bg, paper)
30% → container tokens (cards, sidebars, secondary buttons)
10% → interactive tokens (CTA, active, links)
+ semantic tokens (success/warning/error) — bukan bagian 60:30:10, tapi ikut accent discipline
+ neutral scale 8–10 steps + 4 semantic scales → total 50–80 values dari 5–7 base hues
```

## 4.5 Variasi per mode

- **Light (default):** 60 light neutral, 30 mid brand tint, 10 vibrant.
- **Dark:** 60 dark shade (bukan pure black), 30 dark container, 10 bright accent. Rasio tetap 60:30:10. Invert via `prefers-color-scheme` atau `.dark` class. Test accent tetap standout di kedua mode + contrast AA.
- **Trust-first / public-sector / regulated:** dominant lebih muted, accent desaturated (taste-skill preset VARIANCE 3–4, MOTION 2–3).

## 4.6 Palet per vertikal (starter — ganti sesuai brand, jangan jadi second-order default)

| Vertikal | 60 Dominant | 30 Secondary | 10 Accent | Catatan |
|----------|-------------|--------------|-----------|---------|
| **SaaS / ERP / CRM** | White / Zinc-50 | Slate-100 / muted brand | Electric Blue / Emerald / Ink-blue | Cool, trust, data. Saturation <80% |
| **eCommerce / Marketplace** | White (#fff paper) | Light grey cards / Stone | Warm accent (Rose / Amber) untuk price & CTA | Product canvas = white agar foto product pop |
| **POS** | White canvas transaksi | Light grey catalog grid | High-contrast Pay CTA (Green/Blue) + semantic red untuk void | Speed: accent harus scannable 1m jarak |
| **HR** | Warm Sand / Limestone | Stone / Eucalyptus muted | Humanis warm (Terracotta / Sage) | Whitespace luas, calming — jangan corporate blue generik |
| **SaaS premium consumer** | Cold Luxury: silver-grey+chrome+smoke | — | Satu vibrant (bukan warm beige/brass/oxblood — banned) | Lihat taste-skill premium-consumer ban §4.2 |
| **Fintech** | White + warm near-white | Cool grey | Single jewel / deep trust blue, restraint | Mercury/Ramp school — 1 clear number, bukan wall of charts |

**Contoh real-world:**
- Material Design: 60 white bg, 30 light grey search bar, 10 bright blue links/buttons.
- iOS: 60 white, 30 light grey, 10 blue/green vibrant.
- Spotify: 60 black, 30 dark grey, 10 green accent.

## 4.7 Mistakes yang merusak 60:30:10

- **Overuse accent** — 10% jadi 30% = hierarchy hilang, tombol hilang.
- **>1 accent** — strength = restraint. 2–3 accent = chaos warna.
- **Ignor contrast AA** — 60:30:10 bukan pengganti 4.5:1 body / 3:1 large.
- **Mismatch brand** — framework tapi tidak match personality.
- **Rigid literal** — boleh geser sedikit (55/35/10) sesuai density; jangan dogma 60.0. Uji via grayscale-first: jika flat di grey, warna tidak akan selamatkan.
- **Warm/cool grey clash** — lock 1 neutral family per project (taste-skill lock).

## 4.8 Order kerja (Visily — grayscale-first)

1. Design layout di grayscale dulu — cek hierarchy spacing & contrast.
2. Apply neutral 60 ke bg & large surfaces.
3. Layer 30 secondary ke cards/headers/nav.
4. Reserve 10 accent hanya untuk primary action.
5. Test light + dark.

Jika flat di grey, fix struktur dulu sebelum tambah warna.

## 4.9 Checklist color

- [ ] Tokens OKLCH di `:root`, semua ref via `var()`
- [ ] 60:30:10 area visual terasa (dominant restful, accent rare)
- [ ] 1 accent hue saja, saturasi <80% (kecuali playful)
- [ ] Contrast AA pass (body 4.5:1, large 3:1) light & dark
- [ ] No purple→blue gradient hero tanpa brand reason
- [ ] No unchosen indigo/violet CTA
- [ ] No warm/cool grey clash dalam 1 page
